국가 중심 세계지도(Country-Centered Map)의 수학적 원리:
최고점 대원, 대원의 대칭 대원, 그리고 적도의 삼각함수적 대칭 관계 증명

수학적 구면기하학 및 지도학 연구 논문

요약 (Abstract)

본 연구는 임의의 국가를 중심에 두는 구면 투영 기반의 국가 중심 세계지도에서 형성되는 최고점 대원(Great Circle with Maximum Peak), 대원의 대칭 대원($-Z$ Great Circle), 그리고 적도(Equator) 사이의 공간 수학적 관계를 명확히 규명하고 이를 정밀 증명한다.

웹 인터랙티브 그래프 시뮬레이터

아래 슬라이더를 조절하여 대원의 최고점 위도($\phi_{\max}$) 변화에 따른 원본 좌표계와 평행이동 좌표계에서의 적도 및 대원 그래프를 실시간으로 확인하세요.

1. 서론 (Introduction)

특정 국가나 지점을 중심에 두는 국가 중심 세계지도에서는 투영 중심점의 변환에 따라 지구상의 대원(Great Circle) 및 적도선이 직교좌표계 상에서 정현파(Sine wave) 형태의 곡선으로 변환된다.

2. 구면좌표계 변환 및 나피에르 법칙

$$\cos\lambda = \frac{\cos x}{\cos\phi} \quad \implies \quad \lambda = \arccos\left(\frac{\cos x}{\cos\phi}\right)$$

$$V_g(x) = A_g \sin(x + \delta)$$

대원의 최고점 기준 $f(x) = 0$이 되는 변환 좌표계에서 적도 그래프는 다음과 같이 유도됩니다.

$$\therefore E_g(x) = -f(x) - \phi_{\max}$$

3. Python 오프라인 시뮬레이션 코드

import numpy as np
import matplotlib.pyplot as plt

def plot_spherical_projections():
    x = np.linspace(0, 2 * np.pi, 1000)
    phi_peak_deg = 45.0
    phi_peak = np.radians(phi_peak_deg)
    
    V_g = phi_peak * np.sin(x)
    G_minus = -V_g
    E_g = -V_g
    
    f_x = V_g - phi_peak
    E_g_shifted = -f_x - phi_peak

    fig, (ax1, ax2) = plt.subplots(2, 1, figsize=(10, 8), sharex=True)
    
    ax1.plot(x, np.degrees(V_g), 'r-', label=r'Great Circle $V_g(x)$')
    ax1.plot(x, np.degrees(E_g), 'b-', label=r'Equator $E_g(x) = -V_g(x)$')
    ax1.plot(x, np.degrees(G_minus), 'g--', label=r'$-Z$ Antipodal $G_-(x)$')
    ax1.set_title("1. Original Coordinates")
    ax1.legend()
    ax1.grid(True)
    
    ax2.plot(x, np.degrees(f_x), 'r-', label=r'Shifted Great Circle $f(x)$')
    ax2.plot(x, np.degrees(E_g_shifted), 'b-', label=r'Equator $E_g(x)$')
    ax2.set_title("2. Transformed Coordinates (Peak at $y=0$)")
    ax2.legend()
    ax2.grid(True)
    
    plt.tight_layout()
    plt.show()

if __name__ == "__main__":
    plot_spherical_projections()
