지명·지도 기반 KML 제작 도구

장소 이름을 검색하거나 지도에서 직접 찍어 위치를 등록하고, Google Earth에서 열 수 있는 KML 파일로 저장하세요.

1. 지명 검색으로 위치 추가

검색 결과는 인터넷 지명 검색 서비스를 사용합니다. 결과를 선택하면 지도에 표시됩니다.

2. 기존 KML 파일 열기

KML 파일의 지점과 경로를 지도에 표시합니다. 지점은 편집 목록에 추가되며, 불러온 경로는 별도 레이어로 유지됩니다. KMZ는 압축 파일이므로 현재 버전에서는 지원하지 않습니다.

3. 지도에서 GPS 위치 추가

지도에서 원하는 지점을 클릭하면 위도·경도가 자동 입력됩니다. 아래 버튼으로 현재 기기의 GPS 위치를 가져오거나 좌표를 직접 입력할 수도 있습니다.

지도 클릭 또는 GPS 버튼으로 위치를 선택하세요.

4. 선택한 위치 등록

지도 빈 곳을 클릭하면 좌표가 입력됩니다. 위도·경도를 직접 입력해도 됩니다.

5. KML 정보 및 저장

다운로드한 .kml 파일은 Google Earth에서 열 수 있습니다. 선 연결은 지점 등록 순서대로 만들어집니다.

등록된 지점 (0)

검색 결과를 선택하거나 지도 위를 클릭해 지점을 추가하세요.

지도 작업 공간

지도를 클릭하면 해당 좌표를 선택합니다. 마커를 눌러 지점 정보를 확인할 수 있습니다.

지도 종류에 따라 OpenStreetMap, Esri, OpenTopoMap, CARTO 타일을 사용합니다. 지명 검색과 지도 타일은 인터넷 연결이 필요합니다.

참고: KML은 WGS84 좌표를 사용합니다. KML 좌표 순서는 경도,위도,고도입니다. 해상 투어에서는 실제 출항 전 기상·조류·항로·구조 계획을 별도로 확인하세요.
