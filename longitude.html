국가 중심 세계지도와 대원의 수학적 원리

이동하는 북극점·남극점에 따른 경도 대원의 변화와 구면 좌표변환 모델




1. 구면 좌표와 기본 공식

반지름 R인 구면에서 위도 φ, 경도 λ를 3차원 좌표로 변환합니다.

x = R cosφ cosλ

y = R cosφ sinλ

z = R sinφ

각도는 계산 과정에서 라디안으로 변환합니다.

2. 위도 소원과 경도 대원

Lφ = 2πR cosφ

위도원의 원주는 위도에 따라 코사인 비율로 감소합니다.

Lgreat circle = 2πR

구면 위의 대원은 중심을 통과하므로 반지름 R인 원입니다.

Lmeridian = πR

북극에서 남극까지의 자오선 길이입니다.

3. 새로운 극점 벡터

새로운 북극점의 단위벡터를 p로 정의합니다.

p = (cosφp cosλp, cosφp sinλp, sinφp)

새로운 남극점은 다음과 같습니다.

s = −p

극점의 이동은 좌표계 회전 또는 새로운 위도·경도 체계의 정의로 해석할 수 있습니다.

4. 3차원 구면 위의 새로운 경도 대원

새로운 북극점 새로운 남극점 새로운 경도 대원

구면은 정교한 지구 지도 투영이 아닌, 좌표변환 원리를 설명하는 개념적 시각화입니다.

5. 기존 경위도 지도에 표시

새로운 경도 대원의 3차원 점을 기존 위도·경도 좌표로 역변환해 그립니다. 경도 ±180° 경계에서는 선을 분리합니다.

6. 극점의 사인·코사인 성분

z = R sinφ는 수직 성분, ρ = R cosφ는 수평면에서의 거리 성분입니다.

7. 위도별 원주 비율

위도cos(위도)원주 비율

위도원 원주 = 적도 원주 × cos(위도)입니다.

8. 새로운 경도 대원의 수학적 정의

r(φ′, λ′) = R [cosφ′ · u(λ′) + sinφ′ · p]

여기서 p는 새로운 북극점 방향, u(λ′)는 새로운 적도면 안의 방향 벡터입니다.

새로운 적도면

p · r = 0

회전 행렬 표현

r′ = Qr,   QᵀQ = I,   det(Q) = 1

9. Python 계산 모델

아래 코드는 동일한 수학적 모델을 Python과 NumPy로 계산할 때 사용할 수 있는 핵심 부분입니다.

import numpy as np

R = 1.0
pole_lat_deg = 35.26
pole_lon_deg = 45.0

phi = np.radians(pole_lat_deg)
lam = np.radians(pole_lon_deg)

p = np.array([
    np.cos(phi) * np.cos(lam),
    np.cos(phi) * np.sin(lam),
    np.sin(phi)
])

print("New north pole:", p)
print("New south pole:", -p)

# New great-circle point:
# r = R * (cos(phi_new) * u + sin(phi_new) * p)
